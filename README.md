# SNOWBOUND Android Project

Open this folder in Android Studio and follow `BUILD_APK_TH.md`.

- App ID: `com.snowbound.survival`
- Minimum Android: 8.0 / API 26
- Target / compile SDK: 35
- Orientation: landscape
- Local game asset: `app/src/main/assets/index.html`
- Web runtime: Android System WebView + network-loaded Three.js / PeerJS
